# Personal Expense Tracker
## Description

Personal Expense Tracker is a simple Python project used to record, view, search and analyse daily expenses. It also checks whether the total expense is within the user's budget.

## Features

- Add new expenses
- View all expenses
- Calculate total expenses
- Analyse expenses category-wise
- Search expenses by category
- Check expenses against a budget

## Technologies Used

- Python
- VS Code
- GitHub

## How to Run

1. Open the project folder in VS Code.
2. Open `main.py`.
3. Run the program.
4. Enter the expense details when asked.
5. Follow the options shown by the program.
